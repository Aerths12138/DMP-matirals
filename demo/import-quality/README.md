# 数据导入质量门禁演示用例

这些文件可直接在“数据导入”页面上传。除特别说明外，上传后核对列映射即可；
点击“AI 助手格式对齐”可以继续展示科学计数法订正与订正文件下载。

| 顺序 | 文件 | 预期结果 | 展示重点 |
| --- | --- | --- | --- |
| 1 | `01_clean_scientific.csv` | 质量预检通过 | 合法科学计数法不会被误报，确认按钮可用 |
| 2 | `02_empty_material_name.csv` | 1 个阻断问题，源文件第 3 行 | 空材料名不会再被静默丢弃，确认按钮禁用 |
| 3 | `03_duplicate_names.csv` | 2 个警告，指向第 3、4 行 | 大小写、首尾空格和全角字符归一后识别同名，提示将与第 2 行合并 |
| 4 | `04_mixed_numeric_text.csv` | 1 个警告，源文件第 3 行“拉伸强度”列 | 数值列混入文本时给出行列定位，但不强制阻断 |
| 5 | `05_short_rows.csv` | 质量预检通过 | 缺少尾部可选值的短行仍可导入 |
| 6 | `06_all_text_property.csv` | 质量预检通过 | 整列都是文本时不会被误判为数值污染 |
| 7 | `07_combined_issues.csv` | 1 个阻断问题、2 个警告 | 同时展示空名称、同名合并和混合类型；可下载质量报告 |
| 8 | `08_numeric_formats.csv` | 质量预检通过 | 标准科学计数法、乘号科学计数法、千分位数字均可识别 |
| 9 | `09_missing_name_mapping.csv` | 1 个阻断问题 | 文件没有可识别的材料名称映射时不能确认导入 |

推荐现场演示顺序：先上传 1 展示正常路径，再上传 7 展示门禁与报告，最后上传 3
说明非阻断警告仍允许用户核对后继续。

自动验证命令（从仓库根目录执行）：

```powershell
Push-Location frontend
npm.cmd run test:import-quality
$code = $LASTEXITCODE
Pop-Location
exit $code
```

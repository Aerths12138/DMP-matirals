材料数据管理平台便携版使用说明
================================

一、适用环境
------------

- Windows 10 或 Windows 11，64 位系统。
- 不需要安装 Python、Node.js、数据库或其他开发环境。
- 电脑需要安装任意现代浏览器，例如 Edge、Chrome 或 Firefox。
- 平台仅监听本机地址 127.0.0.1，默认不会被局域网中的其他电脑访问。

二、首次启动
------------

1. 必须先完整解压压缩包，不能直接在 ZIP 压缩包中运行程序。
2. 保留解压后的完整目录，不能只移动 MaterialsDMP.exe。
3. 双击 Start-Materials-DMP.bat。
4. 保持弹出的服务器窗口开启，等待浏览器自动打开：

   http://127.0.0.1:8000

5. 使用以下初始账号登录：

   用户名：admin
   密码：admin123

首次启动时，程序会自动在 data 目录创建数据库、文件存储目录和本机随机密钥。

三、停止平台
------------

可以使用以下任一方式停止：

1. 关闭 Materials DMP 的服务器窗口；
2. 双击 Stop-Materials-DMP.bat。

必须先停止平台，再拔出U盘或移动程序目录，避免数据库正在写入时损坏。

四、数据保存与备份
------------------

所有运行数据都保存在解压目录下的 data 文件夹中，包括：

- materials_dmp.db：平台数据库；
- storage：上传的文件；
- secret.key：本机登录令牌签名密钥。

备份方法：

1. 先停止平台；
2. 复制整个 Materials-DMP-Portable-Windows-x64 文件夹。

不要只备份数据库文件，也不要删除或泄露 secret.key。

五、配置 AI 助手（可选）
------------------------

便携包没有预置 API 密钥。AI助手不是完全离线模型，需要连接可访问的大模型服务。

使用文本编辑器打开 LLM_CONFIG.env，填写：

LLM_BASE_URL=https://模型服务地址/v1
LLM_MODEL=支持工具调用的模型名称
LLM_API_KEY=模型服务密钥

模型接口需要兼容 OpenAI 的 /v1/chat/completions，并支持 tools、tool_choice
和 tool_calls。修改配置后，需要停止并重新启动平台。

如果不使用 AI 助手，保持相关配置为空即可。不要把已经填写 API 密钥的配置文件
交给无权使用该密钥的人。

六、端口被占用
--------------

如果启动时提示 8000 端口已被占用，请编辑 LLM_CONFIG.env，将：

PORT=8000

改为其他未使用端口，例如：

PORT=18000

重新启动后访问 http://127.0.0.1:18000。

七、常见问题
------------

1. 双击后网页打不开

   保持服务器窗口开启，查看窗口中是否出现错误；确认浏览器访问的端口与
   LLM_CONFIG.env 中的 PORT 一致。

2. Windows 阻止程序运行

   本程序是本地构建的未签名程序，Windows SmartScreen 可能提示风险。确认文件
   来源可信后，可点击“更多信息”，再选择“仍要运行”。

3. AI助手无法使用

   检查 LLM_CONFIG.env 中的模型地址、模型名和密钥，并确认目标电脑能够访问该
   模型服务。平台的普通数据管理功能不依赖 AI 服务。

4. 移动后原来的数据不见了

   数据位于 data 文件夹。移动时必须复制整个程序目录，不能只复制 EXE 或启动脚本。

八、文件说明
------------

- Start-Materials-DMP.bat：启动平台；
- Stop-Materials-DMP.bat：停止平台；
- MaterialsDMP.exe：平台主程序；
- _internal：程序运行依赖，不能删除；
- web：网页资源，不能删除；
- data：数据库和上传文件；
- LLM_CONFIG.env：AI模型和端口配置；
- README-PORTABLE.txt：本使用说明。
